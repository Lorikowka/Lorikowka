## Русский

**Сейчас мой фокус:**

### Проекты

#### StoryEngine — сюжетный движок для Minecraft

**Основной проект · Java · Minecraft Forge 1.19.2**

[Репозиторий →](https://github.com/Lorikowka/StoryEngine)

Модульный инструментарий для создания интерактивных историй и игровых сценариев непосредственно в Minecraft.

**Основные системы:**

- **Quest System** — квесты с JSON-описаниями, индивидуальным прогрессом игроков, задачами и наградами.
- **Narrative HUD** — сюжетные реплики с именем персонажа, иконкой, очередью сообщений и эффектом печати текста.
- **Dialogue System** — ветвящиеся диалоги с вариантами ответа, условиями и действиями.
- **Interaction Hint System** — контекстные подсказки взаимодействия и маркеры ближайших объектов.
- **Конфигурация и расширяемость** — редактирование игровых данных, настройка интерфейса и инструменты интеграции со скриптами HollowEngine.

Одна из целей проекта — дать авторам возможность настраивать сюжетные системы через конфигурации и команды, а не писать отдельный код для каждого события.

**Технологии проекта:** Java 17, Minecraft Forge 1.19.2, JSON, Gradle.

### Projects

#### StoryEngine — a narrative toolkit for Minecraft

**Main project · Java · Minecraft Forge 1.19.2**

[View repository →](https://github.com/Lorikowka/StoryEngine)

A modular toolkit for creating interactive stories and gameplay scenarios directly in Minecraft.

**Key systems:**

- **Quest System** — JSON-defined quests, per-player progress, objectives, and rewards.
- **Narrative HUD** — character messages with names, icons, queued dialogue, and typewriter effects.
- **Dialogue System** — branching dialogue with choices, conditions, and actions.
- **Interaction Hint System** — contextual interaction hints and nearby-object markers.
- **Configuration and extensibility** — editable gameplay data, UI customization, and integration tools for HollowEngine scripts.

The project's goal is to make narrative mechanics easier to configure and reuse, reducing the need to implement every story event from scratch.

**Project technologies:** Java 17, Minecraft Forge 1.19.2, JSON, Gradle.

### Development philosophy

- Understand how a system works, not just what it does.
- Prefer maintainable and extensible solutions.
- Treat gameplay features as interconnected components.
- Keep learning through practical development and iteration.

This profile will grow alongside my projects, experiments, and completed work.
